# Mini Core Bank (Spring Boot)

Mini Core Bank là dự án mini mô phỏng các chức năng nền tảng của core banking: onboarding khách hàng và mở tài khoản thanh toán. Project dùng Spring Boot + JPA + Flyway + MySQL/MariaDB (Laragon).

---

## Tech Stack

- Java: **17+** (bạn đang chạy Java 24 cũng OK)
- Spring Boot: 4.x
- Spring Web, Validation
- Spring Data JPA (Hibernate)
- Flyway (DB migrations)
- MySQL/MariaDB (Laragon)
- Lombok
- Spring Security (đang mở API để dev/test)
- Springdoc OpenAPI (Swagger UI)

---

## Yêu cầu trước khi chạy

- JDK 17+ (khuyên dùng 17 hoặc 21)
- Maven 3.9+
- Laragon (MySQL/MariaDB) hoặc MySQL local
